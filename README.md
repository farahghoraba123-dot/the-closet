# THE CLOSET

Minimal online store front end for THE CLOSET.

## Pages
- `index.html`: homepage and category navigation
- `products.html`: collection page
- `checkout.html`: cash-on-delivery order request form

## Add products later
Edit `products-data.js`. Add each product with a name, category, price, and image path. Put product images in the repository and use the matching path. Supported categories: `hoodies`, `denim`, `jackets`, `jeans`, `sweatpants`, `essentials`.

## Size guide
Sizes M, L, XL, XXL. Garment measurements are intentionally pending until each item is measured.

## Orders
Checkout is COD only. The form uses FormSubmit and requires confirming its activation email after the first test submission. Submit a test order and confirm it arrives at the store inbox before accepting customer orders.

## Hosting
GitHub Pages hosts the static website only. It does not provide inventory, secure order management, or payment processing.
